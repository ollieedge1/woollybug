Frequently asked

A fly tying hook chart lists hooks by manufacturer and model alongside their specifications — size range, wire strength, shank length, gape and eye type — so tyers can pick the right hook for a pattern. Traditional charts are static PDFs covering a single brand; the Woolly Bug Hook Finder is a searchable database covering 700+ hooks from 16 manufacturers.

A hook comparison chart (or cross-reference chart) maps equivalent hooks across manufacturers — for example, which Ahrex or Fulling Mill hook matches a given Tiemco model. Hook Finder does this instantly by comparing real specifications rather than relying on out-of-date printed tables.
