Convert Your Fly Tying Spreadsheet with AI

Already keep your materials in Excel, Numbers or Google Sheets? You don't need to retype a thing. An AI assistant can reshape your sheet into Woolly Bug's import format in a couple of minutes.

Woolly Bug teamUpdated October 20264 min read
Five steps
  1. Export your spreadsheet
  2. Copy the Woolly Bug prompt
  3. Ask an AI assistant to convert it
  4. Check the result
  5. Import it into Woolly Bug

Woolly Bug imports a CSV with its own set of columns: Name, Category, Brand, Colour, Size, where it's stored and so on. Your spreadsheet almost certainly uses different headings, different category names, or packs several details into one cell. Rather than rearrange it by hand, let an AI assistant do the reshuffling.

1. Export your spreadsheet

Save or download your sheet as a CSV or Excel file. In Numbers use File → Export To → CSV, in Excel Save As → CSV UTF-8, and in Google Sheets File → Download → CSV. If your materials are split across several tabs, export each one.

2. Copy the Woolly Bug prompt

This prompt tells the AI exactly which columns Woolly Bug expects and which values it accepts. You'll find the same prompt in the app: Import Inventory → step 2 → Copy AI prompt.

Woolly Bug conversion prompt
I'm moving my fly tying materials into the Woolly Bug app. Please convert the spreadsheet I've attached into a CSV file that Woolly Bug can import.

Use exactly these column headers, in this order:
Name,Variant,Category,Brand,Color,Size,Code,Supplier,Quantity,Storage Location,Stock Status,Barcode,Notes,Hook Category,Hook Geometry,Shank Length,Eye Type,Wire Strength,Gape,Barbed

Rules:
- One row per material. Name is required. Leave any other cell empty if my spreadsheet doesn't have that information.
- Category must be one of: Beads, Dubbing, Feathers, Fur, Glue/Varnish, Hair, Hooks, Synthetics, Thread/Floss, Wire/Tinsel, Other.
- Stock Status must be In Stock, Low or Out. Use In Stock if you can't tell.
- Quantity is a whole number.
- The hook columns are only for hooks:
  - Hook Category, e.g. Dry Fly, Nymph, Wet Fly, Streamer, Emerger, Midge, Scud, Terrestrial, Saltwater, General Purpose
  - Hook Geometry: Straight, Curved, Jig/90°, Kink Shank
  - Shank Length: Standard, 1X Long, 2X Long, 3X Long, 4X Long, 1X Short, 2X Short
  - Eye Type: Ring Eye, Down Eye, Up Eye, Looped, Tapered
  - Wire Strength: Standard, 1X Heavy, 2X Heavy, 3X Heavy, 1X Fine, 2X Fine
  - Gape: Standard, Wide, Extra Wide
  - Barbed: Yes or No
- Use a dot for decimals (3.5mm, not 3,5mm). Put any value that contains a comma in double quotes.
- Don't invent anything that isn't in my spreadsheet.

Give me the result as a downloadable .csv file. If you can't create files, give me the CSV in a code block so I can save it as a .csv file.

3. Ask an AI assistant to convert it

Open ChatGPT, Claude or Gemini, start a new chat, paste the prompt and attach your file. If your assistant can't take attachments, paste the rows from your spreadsheet straight under the prompt instead.

You'll get back a CSV file to download, or a block of CSV text. If it's text, copy it into a plain text editor and save it with a .csv ending.

4. Check the result

Open the new file and give it a quick look before importing:

  • One row per material, with every row having a Name.
  • Categories come from Woolly Bug's list (Beads, Dubbing, Feathers, Fur, Glue/Varnish, Hair, Hooks, Synthetics, Thread/Floss, Wire/Tinsel or Other).
  • Nothing made up. Empty cells are fine; only Name is required.
Big collection? Ask the AI to do it in batches of a few hundred rows, then combine the files, or import them one after another. Importing again only adds new materials and updates matching ones.

5. Import it into Woolly Bug

In the app, open Settings → Library → Import / Export Inventory → Import Inventory and choose your file. Woolly Bug shows you a preview of what it found before anything is added, and you can undo the last import if something isn't right.

Frequently asked questions

Can AI convert my fly tying spreadsheet for Woolly Bug?

Yes. Paste the Woolly Bug prompt into ChatGPT, Claude or Gemini and attach your spreadsheet. The prompt tells it the exact columns and accepted values, so it returns a CSV you can import straight into the app.

Which AI assistant should I use?

Any assistant that can read an attached file works, including ChatGPT, Claude and Gemini. If yours can't attach files, paste the rows from your spreadsheet into the chat under the prompt instead.

Will the AI change or invent my data?

The prompt asks it not to invent anything and to leave cells empty when your sheet doesn't have the information. Always skim the result before importing; it takes a minute and catches the odd mistake.

Is my spreadsheet private?

Your file goes to whichever AI service you choose, under that service's privacy terms, not to Woolly Bug. If you'd rather not share it, fill in the Woolly Bug template by hand instead.

Do I need Woolly Bug Pro to import?

Yes, importing a spreadsheet is part of Woolly Bug Pro. Converting your file with AI is free to try first, so you can check the result before you upgrade.
